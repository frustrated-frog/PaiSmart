# 知枢桌面端 UI 与交互改造设计

## 1. 背景与目标

知枢是面向企业知识管理和 Agentic RAG 的桌面 Web 控制台。本轮不考虑手机和平板适配，目标是在不改动业务接口的前提下，让页面同时具备：

- 企业知识产品应有的信息密度和可信度；
- Agent 执行过程可解释、可观察的技术辨识度；
- 亮色与暗色主题一致的视觉语义；
- 清晰、克制、便于演示的桌面端操作路径。

本轮不重做现有前端框架，不引入新的 UI 组件库，不改变后端协议。

## 2. 设计方向

### 2.1 产品定位

视觉定位为“知识智能控制台”，而不是通用管理后台。用户首先看到的是知识、会话和 Agent 执行状态，组织、充值等管理能力退居次级导航。

### 2.2 视觉 Token

| Token | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `knowledge-indigo` | `#5657D9` | `#8B8CFF` | 主操作、选中态 |
| `signal-cyan` | `#0891B2` | `#22D3EE` | 检索、运行信号 |
| `evidence-emerald` | `#059669` | `#34D399` | 证据充分、成功状态 |
| `surface-canvas` | `#F5F7FB` | `#111318` | 页面底色 |
| `surface-panel` | `#FFFFFF` | `#191C22` | 主面板 |
| `ink-primary` | `#172033` | `#EEF2FF` | 主文字 |

字体不加载远程资源。标题使用 `Avenir Next / SF Pro Display / PingFang SC`，正文使用 `Inter / SF Pro Text / PingFang SC`，运行指标使用 `SFMono-Regular / Menlo`。

圆角只保留三级：控件 `8px`、卡片 `12px`、主容器 `16px`。阴影只用于浮层和主工作区，不为每张卡片单独制造悬浮感。

### 2.3 标志性元素

唯一的标志性视觉元素是“检索执行轨道”：

`Query → BM25 / Vector → RRF → Rerank → Evidence`

它会以两种密度出现：

- 登录页：作为产品能力的静态演示，帮助面试演示快速建立认知；
- Agent 对话：作为真实执行过程的摘要，可展开查看运行指标。

不在其他页面重复使用大型渐变、光晕或装饰图形。

## 3. 信息架构

### 3.1 左侧导航

保留路由和权限模型，仅改变菜单展示分组：

1. 核心工作台：聊天助手、知识库、聊天记录；
2. Agent 治理：模型配置、用量监控；
3. 组织与系统：用户管理、组织标签、邀请码管理；
4. 账户服务：个人中心、余额充值、充值管理。

分组标签只负责建立层级，不可点击。折叠侧栏时隐藏分组标签，仍保留原路由图标和 Tooltip。

### 3.2 顶部页头

移除无语义的左侧空白区域。页头左侧展示当前页面中文标题和一句短描述；右侧保留搜索、全屏、主题和账号入口。聊天时间筛选回到聊天工作区，不再 Teleport 到全局页头。

## 4. 核心页面

### 4.1 Agent 对话

- 会话侧栏保留 260px，但降低装饰和信息噪音；
- 30 天运行健康度默认折叠为一行摘要，点击后查看成功率、P95、平均步骤和恢复次数；
- 空会话展示三个可直接填入输入框的场景提示；
- 消息区控制在适合阅读的宽度，用户问题与 Agent 回答通过背景、对齐和标签建立角色差异；
- Agent 执行轨道默认展示当前阶段和结果摘要；
- 详细预算、工具、Token 和证据指标放入可展开区域；
- 已完成但缺少 `terminalReason` 的运行显示 `COMPLETED`，仅最后一步仍在处理中时显示 `RUNNING`；
- 错误状态提供明确的“重新生成”操作。

### 4.2 模型配置

- 移除硬编码白色和 `stone-*` 颜色，完全使用主题变量；
- 当前配置展示为“JD Cloud GLM-5”或根据接口数据展示的兼容提供方；
- 顶部只展示当前提供方、模型、连接状态和能力标签；
- URL、Key、Model 等详细配置放入结构清晰的配置区；
- 测试连接结果同时展示成功状态和延迟。

### 4.3 知识库

- 表格上方增加页面说明和主要操作；
- 空状态不再只显示“无数据”，而是提供“上传第一份文档”；
- 使用五段处理链路解释文档进入 RAG 的过程：上传、解析、分块、向量化、索引；
- 保留现有表格和上传逻辑，不改变列定义及 API。

### 4.4 登录

- 桌面端改为左右双栏：左侧能力说明，右侧登录表单；
- 左侧通过检索执行轨道展示 Agentic RAG 技术路径；
- 登录卡片不使用大面积装饰性渐变；
- “记住我”改为只保存用户名，绝不在 localStorage 中保存明文密码；
- 协议和隐私入口若尚无落地页面，使用说明文案而不是伪链接按钮。

## 5. 交互与无障碍

- 可点击的会话、Tab 和展开控件使用 `button` 或补齐键盘语义；
- 所有图标按钮提供 `aria-label`；
- Focus 状态使用主色外圈，不依赖浏览器默认样式；
- 动画集中在页面进入、会话选择和执行轨道状态变化；
- 尊重 `prefers-reduced-motion`，关闭非必要位移和循环动画；
- 空状态说明下一步，错误状态说明恢复动作。

## 6. 验证标准

- 桌面宽度 1280px、1440px、1728px 下内容层级稳定；
- 亮色和暗色主题下模型配置输入值、标签和边界均清晰可见；
- 登录存储中不存在密码；
- Agent 结束状态不再错误显示为 `RUNNING`；
- 导航分组不改变原有权限过滤和路由跳转；
- 前端类型检查、相关单测、Lint 和构建通过；
- 在 `http://localhost:9527` 对登录、聊天、知识库、模型配置进行真实浏览器回归。

## 7. 范围边界

本轮不包含：

- 手机和平板响应式改造；
- 后端接口、数据库或 Agent 编排逻辑变化；
- 新增模型供应商管理能力；
- 新增协议和隐私页面；
- 全站所有管理表格的视觉重构。
