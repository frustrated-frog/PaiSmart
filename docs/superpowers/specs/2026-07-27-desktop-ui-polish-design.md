# 桌面端界面精修设计

## 背景

本轮针对实际桌面浏览器截图中暴露的细节问题做结构性修复，不调整品牌方向、不扩展移动端适配，也不改变聊天业务逻辑。

## 问题与根因

1. 顶部标题与说明共用紧凑的基线布局，标题、说明和页面边界缺少明确节奏；截图裁切或可用宽度下降时更显拥挤。
2. 全局导航折叠按钮绝对定位在滚动菜单内部，菜单内容较长时会覆盖“个人中心”“余额充值”等业务菜单。
3. Markdown 组件会在 `.vp-doc` 内渲染一个嵌套 `body` 节点，该节点继承全局 `body` 背景色，导致 AI 回答正文出现额外深色矩形。
4. 对话列表和回答区被放进同一个圆角外框，内部再用边框切分，形成“两张卡片硬接”和重复描边。

## 设计目标

- 顶部标题在 1280px 及更宽桌面窗口中保持完整、安全的左侧留白和清晰层级。
- 导航折叠按钮始终位于独立底栏，不进入菜单滚动流，不覆盖任何业务项。
- AI 正文与页面背景融为同一阅读面，仅通过头像、排版和轻量左侧导线建立身份层级。
- 对话列表与回答区成为两个独立面板，中间保留 12px 工作区间距；收起列表后间距同步消失。
- 不增加高频动画；只保留 160–200ms 的透明度、颜色和按钮按压反馈。

## 视觉方案

### 顶部信息条

保留 `KNOWLEDGE AGENT` 作为页面语义标签。标题与说明位于同一行，但使用 1px、16px 高的分隔线，并将标题设为不可压缩，说明文本才允许截断。整个信息块拥有固定 24px 水平安全区。

### 全局导航底栏

菜单滚动容器只包含分组和业务入口。折叠按钮移到其外部，放入 44px 高的固定底栏，顶部使用发丝分隔线。展开时显示“收起导航”，收起时只保留图标并提供明确的 `aria-label`。

### 聊天双栏

外层只负责页面留白，不再绘制统一大卡片。对话列表和主聊天区各自拥有圆角、边框和面板底色，中间 12px 留白显示画布底色。对话列表收起时宽度归零、边框隐藏，主聊天区自然占满。

### AI 回答正文

对 Markdown 根节点和内部嵌套 `body` 显式设置透明背景、零外边距和继承文字颜色。正文采用 14px、1.75 行高，段落与列表间距收紧；代码块仍保留独立背景，不受本次透明规则影响。

## 验收标准

- 顶部标题左侧不贴边，标题和说明之间存在稳定分隔。
- 滚动到导航底部时，折叠按钮不覆盖个人中心、余额充值或充值管理。
- AI 普通文本回答不出现整块黑色背景；代码块仍可区分。
- 对话列表和主聊天区之间存在连续 12px 间距，圆角互不接触。
- 现有聊天、会话切换、折叠、日期筛选和 Agent 运行面板交互保持可用。

## 范围外

- 手机和平板响应式布局。
- Agent 后端行为、模型调用和知识检索逻辑。
- 全站视觉体系重构或新主题。
